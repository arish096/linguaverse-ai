## ✨ About the Project

**LinguaVerse AI** is a modern language learning platform that combines interactive learning experiences with AI-powered assistance.

Whether you're starting with your first words or improving your fluency, LinguaVerse AI provides a structured learning environment to help you progress at your own pace.

The platform brings together language courses, vocabulary practice, quizzes, achievements, progress tracking, and AI-assisted conversations in one place.

## ⚙️ Getting Started

Follow these steps to run LinguaVerse AI locally.

### 1. Clone the Repository

```bash
git clone https://github.com/arish096/linguaverse-ai.git
```

### 2. Navigate to the Project

```bash
cd linguaverse-ai
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

If you're running the AI backend, create a local `.env` file in the project root and configure your own API key:

```env
OPENROUTER_API_KEY=your_api_key_here
```

**Important:** Never upload your `.env` file or expose API keys publicly.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

> Start the backend separately using its configured start command when AI features require it.
